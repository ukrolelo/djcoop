System Information
Multi-User Setup

This system is designed for multi-user email access. Superadmins can:

  • Create and manage email accounts
  • Grant/revoke user access to specific accounts
  • Set access levels (Read Only / Full Access)
  • Monitor user activity and permissions
Security Features
  • Fernet encryption for email passwords
  • User-based access control
  • Audit trail for permission changes
  • Separation of admin and user interfaces
